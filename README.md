# 🏥 SmartQueue

Hey! Welcome to SmartQueue 👋

SmartQueue is a simple queue management system built to solve a common problem in clinics — long waiting times and confusion in crowded waiting rooms.

The idea behind this project is simple: connect the receptionist and patients through a digital queue system so patients don't have to repeatedly ask "mera number kab aayega?"

This project was built for a hackathon with the goal of creating a practical solution using a clean UI, real-time updates, and AI-based insights.

## ✨ Features

### Receptionist Dashboard

The receptionist can easily manage the clinic queue from one place.

Features include:
- Add new patients
- Assign priority:
  - Emergency
  - Senior Citizen
  - Normal
- Manage live tokens
- Update patient queue status

### Patient App

Patients can check their queue status from their phone without standing near the reception desk.

They can see:
- Current token number
- Number of people ahead of them
- Estimated waiting time
- Live queue updates

### Aura AI Assistant

Aura is an AI-based feature that helps analyze the queue.

It can:
- Monitor the current queue
- Identify rush hours
- Provide clinic status updates
- Help understand patient flow

### UI Features

- Responsive design
- Dark mode
- Smooth animations
- Simple and clean interface
